PORTOFOLIO ANINDITA — PETUNJUK SINGKAT

ISI FOLDER
- index.html: kode website utama
- assets/foto-wisuda.jpg: simpan foto wisuda Anda dengan nama ini

CARA MENJALANKAN DI VS CODE
1. Ekstrak folder anindita-portfolio.
2. Buka folder tersebut di Visual Studio Code.
3. Masukkan foto wisuda ke folder assets dan beri nama foto-wisuda.jpg.
4. Buka index.html di browser (klik dua kali) atau gunakan ekstensi Live Server di VS Code.

SEBELUM DIPUBLIKASIKAN
- Ganti emailkamu@example.com dengan email aktif pada bagian Kontak.
- Tambahkan tautan LinkedIn jika ingin.
- Periksa ulang nama universitas, riwayat, dan angka hasil pengujian skripsi.
- Pastikan foto yang digunakan memang ingin ditampilkan secara publik.

GITHUB PAGES
- Buat repository baru di GitHub.
- Unggah index.html dan folder assets (termasuk foto).
- Buka Settings > Pages.
- Pilih deploy from branch, pilih branch main dan folder /(root), lalu Save.
- Tunggu proses selesai dan gunakan URL yang diberikan GitHub Pages.

CATATAN
Website menggunakan Tailwind CSS CDN, Google Fonts, dan Lucide CDN, jadi koneksi internet diperlukan untuk memuat gaya, font, dan ikon eksternal.
